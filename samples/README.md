# Пустые формы (образцы)

В репозитории нет рабочих файлов с данными сотрудников — вместо них здесь лежат
**пустые копии**: та же форма, но без людей, смен и часов.

| Файл | Куда скопировать | Что это |
|---|---|---|
| `ГРАФИК_ФОРМА A3.xlsx` | в корень проекта | форма графика (А3): шапка утверждения, участки, дни месяца; смены пустые |
| `табель.xlsx` | в папку `backend/` | форма табеля Т-13: шапка и таблица, строки сотрудников пустые |
| `план-факт август2026.xlsx` | в корень проекта | пример входного файла план-факта (недельные листы без людей) |
| `plan_fact.db` | в папку `backend/` | пустая база со схемой (можно не копировать — приложение создаст её само) |

Что сохранилось при очистке: оформление, объединённые ячейки, ширины колонок,
области печати, шапка и подписи. Что удалено: ФИО, должности, участки, смены,
часы и примечания.

Пересоздать образцы из рабочих файлов:

```powershell
.venv\Scripts\python.exe tools\git-prep\make_empty_samples.py
```

Скрипт сам проверяет результат и падает с ошибкой, если где-то осталось ФИО.
