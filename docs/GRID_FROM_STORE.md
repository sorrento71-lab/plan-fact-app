# Сетка графика из базы — что осталось сделать

Краткая инструкция для следующего шага переделки «правка без Excel».
Всё, что ниже упоминается, уже лежит в репозитории и проверено.

## Что уже готово

- `models.ScheduleCell` — ячейки листа (год, месяц, строка, колонка, значение);
- `models.ScheduleMerge` — объединения листа (row1, col1, row2, col2);
- `schedule_store.import_sheet(db, year, month)` — импорт листа: 1384 ячейки;
- `schedule_store.import_merges(db, year, month)` — импорт объединений: 61;
- `schedule_store.load_cells` / `load_merges` — чтение из базы;
- `schedule_store.save_cells` / `set_value` / `get_cell` — запись и удаление;
- `schedule_store.add_employee(db, year, month, name, position, section)` —
  вставка сотрудника в участок: сдвиг строк и объединений, продление
  объединения участка (проверено: «Мастер» B9:B12 → B9:B14);
- `GET /schedule/store/` — отдаёт ячейки из базы;
- `POST /schedule/employee/` — кнопка «Добавить» пишет в базу.

## Что нужно сделать (один шаг)

В `schedule_grid.load_schedule_grid` брать значения и объединения из базы,
если за месяц уже был импорт, иначе — из файла (обратная совместимость).

1. В начале функции (после `year, month` и проверки файла):

```python
import schedule_store
store_cells = schedule_store.load_cells(db, year, month) if db is not None else {}
store_merges = schedule_store.load_merges(db, year, month) if db is not None else []
use_store = bool(store_cells)
```

2. Значения ячеек: при формировании `item['v'] = text` подменять текст
   значением из `store_cells.get((r, c))`, если `use_store`.
   Пустая строка в базе означает «ячейка пустая» — `text = ''`.

3. Объединения: массив `merges` формировать из `store_merges`
   (после приведения к координатам интерфейса через `adj_r`/`adj_c`),
   если `use_store`; иначе — как сейчас, из `ws.merged_cells.ranges`.

4. Оформление (заливки, рамки, шрифты) можно продолжать брать из файла —
   оно не ломается при правке данных.

## Проверка после правки

- `GET /schedule/grid/?year=2026&month=11` — 60 сотрудников, 12 участков,
  те же смены, что и раньше (сверить с листом);
- добавить сотрудника кнопкой в «Мастер» → в сетке он появляется
  внутри участка «Мастер», следующие участки не сдвинуты;
- `DELETE`/очистка ячейки через интерфейс — отражается в базе и в выгрузке.

## Когда сетка будет из базы

- экспорт xlsx (кнопка «Выгрузить форму») собирать из `load_cells`/`load_merges`;
- файл используется только для загрузки (импорта) и выгрузки (экспорта).
